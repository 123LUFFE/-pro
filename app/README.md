# 自动点击Pro (AutoClickPro)

一个功能强大的Android自动化点击应用，支持屏幕录制操作、模拟点击、浮动按钮控制等功能。

## 功能特性

### 核心功能
- **屏幕录制** - 录制用户的触摸操作轨迹（点击、长按、滑动）
- **操作回放** - 精确模拟人手点击，执行录制的操作
- **多脚本管理** - 支持录制和保存多个操作脚本
- **浮动按钮** - 屏幕上显示可拖动、可调整大小的执行控制按钮

### 高级功能
- **操作编辑** - 可视化编辑已录制的操作
- **循环执行** - 支持设置循环次数和循环间隔
- **速度调节** - 0.1x ~ 3.0x 执行速度可调
- **条件判断** - 支持基于颜色/图片/文字的条件判断（预留接口）

## 系统要求

- Android 12 (API 31) 或更高版本
- Kotlin 1.9.20

## 权限说明

应用需要以下权限才能正常工作：

1. **无障碍服务 (Accessibility Service)**
   - 用于模拟点击、滑动等手势操作
   - 需要在系统设置中手动开启

2. **浮动窗口权限 (SYSTEM_ALERT_WINDOW)**
   - 用于显示浮动控制按钮
   - 需要在系统设置中授权

3. **屏幕录制权限 (MediaProjection)**
   - 用于录制触摸操作
   - 首次录制时会请求授权

## 使用说明

### 1. 首次使用

1. 安装应用后，打开应用
2. 根据提示开启无障碍服务权限
3. 授予浮动窗口权限

### 2. 录制操作

1. 点击主界面右下角的"开始录制"按钮
2. 授予屏幕录制权限
3. 在屏幕上进行操作（点击、滑动、长按）
4. 点击"停止录制"按钮
5. 输入脚本名称并保存

### 3. 执行脚本

**方式一：直接执行**
- 在脚本列表中点击"执行"按钮

**方式二：浮动按钮执行**
- 点击"浮动按钮"按钮，显示浮动控制按钮
- 点击浮动按钮开始/停止执行
- 长按浮动按钮打开设置面板

### 4. 编辑脚本

1. 点击脚本卡片的更多选项（三个点）
2. 选择"编辑"
3. 可以修改操作参数、调整顺序、添加/删除操作

### 5. 设置

- 调整默认执行速度
- 调整默认按钮大小
- 开关震动反馈
- 开关状态通知

## 操作类型说明

| 操作类型 | 说明 | 参数 |
|---------|------|------|
| 点击 | 单击屏幕指定位置 | X坐标, Y坐标, 持续时间 |
| 长按 | 长按屏幕指定位置 | X坐标, Y坐标, 持续时间(>500ms) |
| 滑动 | 从起点滑动到终点 | 起点坐标, 终点坐标, 持续时间 |
| 等待 | 等待指定时间 | 持续时间 |
| 循环开始 | 标记循环开始 | 循环次数 |
| 循环结束 | 标记循环结束 | - |

## 技术实现

### 核心技术
- **MediaProjection API** - 屏幕录制和触摸事件捕获
- **AccessibilityService** - 手势模拟执行
- **WindowManager** - 浮动窗口实现
- **Kotlin Coroutines** - 异步操作处理
- **StateFlow** - 响应式状态管理
- **Gson** - JSON序列化存储

### 架构设计
- MVVM架构模式
- Repository模式数据层
- 单例服务管理

## 编译构建

### 环境要求
- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Gradle 8.2

### 构建步骤

```bash
# 克隆项目
git clone https://github.com/your-repo/AutoClickPro.git

# 进入项目目录
cd AutoClickPro

# 构建Debug版本
./gradlew assembleDebug

# 构建Release版本
./gradlew assembleRelease
```

## 注意事项

1. **无障碍服务**是敏感权限，请确保在可信场景下使用
2. 部分系统可能限制后台服务的运行，请将应用加入白名单
3. 录制的坐标基于屏幕分辨率，不同设备可能需要调整
4. 执行速度过快可能导致目标应用无法响应
